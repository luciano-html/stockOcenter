# Reglas del Proyecto (Stock Office Center)

## Git y Despliegue
- **PROHIBIDO hacer `git commit` o `git push` automáticamente.**
- El agente NUNCA debe ejecutar commits ni pushes a menos que el usuario lo solicite explícitamente en el mensaje actual (ej. "hacé commit", "pusheá los cambios", "subí a producción").
- Todos los cambios de código, refactors, pruebas y resoluciones de bugs deben permanecer en el entorno local de trabajo hasta recibir la orden directa del usuario.
